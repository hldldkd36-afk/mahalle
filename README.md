# فروشگاه لوازم جانبی موبایل

این پروژه از قبل آماده شده تا با کمترین تنظیمات اجرا شود.

## اجرای ساده روی کامپیوتر

1. برنامه Node.js نسخه 20 یا جدیدتر را نصب کنید.
2. پوشه پروژه را باز کنید.
3. فایل `.env.example` را کپی کنید و نام نسخه کپی را `.env` بگذارید.
4. داخل ترمینال همین پوشه، این دستورها را یکی‌یکی اجرا کنید:

```bash
npm install
npx prisma generate
npx prisma db push
npm run db:seed
npm run dev
```

5. مرورگر را باز کنید و به `http://localhost:3000` بروید.

## ورود مدیر

- آدرس: `/admin/login`
- نام کاربری و رمز عبور را از فایل `.env` بخوانید و قبل از انتشار عوض کنید.

## انتشار آنلاین با GitHub و Railway

این پروژه فایل تنظیمات Railway را دارد. برای نگهداری دائمی دیتابیس SQLite باید در Railway یک Volume بسازید و مسیر اتصال آن را دقیقاً `/data` قرار دهید. سپس این متغیرها را در بخش Variables پروژه Railway وارد کنید:

```env
DATABASE_URL=file:/data/shop.db
ADMIN_USERNAME=یک-نام-کاربری-دلخواه
ADMIN_PASSWORD=یک-رمز-قوی-و-طولانی
SESSION_SECRET=یک-رشته-تصادفی-حداقل-۳۲-کاراکتری
```

بعد از اتصال مخزن GitHub به Railway، تنظیمات `railway.json` فرمان ساخت و اجرای برنامه را مشخص می‌کند. فرمان شروع، ساختار دیتابیس را به‌روز می‌کند و محصولات و نوشته‌های نمونه را فقط در صورت نبودن اضافه می‌کند.

**نکته:** فایل SQLite باید داخل Volume باشد؛ اگر مسیر `/data` را تنظیم نکنید، ممکن است اطلاعات دیتابیس پس از راه‌اندازی مجدد از بین برود.
